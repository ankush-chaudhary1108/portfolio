# Ankush Chaudhary — Portfolio

A simple Gatsby portfolio customized for Ankush Chaudhary, B.Tech CSE student at VIT Vellore. It includes an introduction, projects/experience, participation certificates from graVITas 2026, and contact placeholders.

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm start` to launch the development site (usually at `http://localhost:8000`).
4. Run `npm run build` for a production build.

## Before publishing
- Replace email, LinkedIn, and GitHub placeholders in `src/components/ContactLinks.js`.
- Review project wording and add links/screenshots if you have them.
- Deploy to a static host such as Netlify or Vercel after the build succeeds.
